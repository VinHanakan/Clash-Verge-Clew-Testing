# 已知限制

[English](KNOWN_LIMITATIONS.md) | 简体中文

- 应用流量接管仅覆盖 Windows IPv4 TCP。IPv6 和 UDP **不由此功能接管**，仍走操作系统／应用原有网络路径，可能绕过所选应用出口。本功能不是防泄漏或严格阻断模式。
- 对显式使用本地或远程代理的应用，Mihomo 不一定保留其原始进程身份。未经单独端到端验证，不要假定该应用的 HTTP/SOCKS 流量与直连 TCP 遵循相同策略。
- 回环、局域网和 DNS 行为遵循当前 Clew/Mihomo 的排除与解析路径；本功能不能替代整机 DNS 或 TUN。应用代理模块不修改系统 DNS 或系统代理设置。
- 转发运行期间禁止切换 profile／订阅。请先停止应用代理，再切换配置、核对策略组引用并手动启动。保存规则不代表在重启、登录或启动应用后自动恢复转发。
- 指定策略组名称必须存在于当前生效的 Mihomo 配置。组被删除或改名时应显示错误／不可用，不得静默降级到 `regular` 或直连。
- 规则匹配依赖 Clew 的命令行和进程行为。系统会拒绝匹配全部 `node.exe` 或 `python.exe` 等宽泛解释器规则，应指定脚本命令行。Windows 进程遥测未必提供完整命令行，因此不能总是仅凭进程列表安全地创建脚本规则。
- 不同出口的应用规则若重叠，目前没有已验收的优先级约定。应为各出口使用不同的可执行文件路径或命令行模式，不要依赖列表顺序解决冲突。
- helper API 当前为占用本地 `18080` 端口的单实例。若端口已由其他进程占用，启动应报错；不得结束占用者，也不得将其视为本实例的 helper。
- 内部安装器未签名。应用更新检查、安装、更新产物与端点均已禁用；不承诺自动更新、驱动自动修复、崩溃时严格阻断或完整的运行中配置迁移。
- 托盘图标在各模式下使用同一图形；托盘提示和菜单仍显示代理模式。尚未重建按模式变化的图标。
- `internal-test` 构建始终以 sidecar 方式启动 Mihomo，并拒绝服务安装、修复和卸载命令；不管理上游 Clash Verge 服务。
- 正式独立 Windows 安装器仍被禁用，须先将继承的服务及卸载路径与 Clash Verge Rev 完全隔离。仅允许构建隔离的 `internal-test` 包；其应用数据不会自动从先前的 internal-test 标识迁移。
- 开发机上的 Rust 单元测试可执行文件目前以 `0xc0000139` 返回，导致测试无法启动。这是运行依赖阻碍，**不能**记为测试通过。
