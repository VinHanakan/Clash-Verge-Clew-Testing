# Application icon

English | [简体中文](README.zh-CN.md)

`../Clash Verge Clew.png` is the original image supplied by the project owner. `app-icon-source.png` is the edited icon used to generate the packaged assets in `src-tauri/icons/` and `src/assets/image/`.

The edit preserved the white cat-head and paw line art and the blue/purple rounded-square field, changing the opaque outside corners to transparency. It was made with the built-in image editing tool using this instruction: “Preserve the exact cat-head and raised paw white line drawing; change only the external near-white corner area outside the rounded-square silhouette to genuine alpha transparency; no text or added elements.” App, installer, and frontend icon sizes were then generated with the Tauri CLI.

The default tray icon uses the same mark in all proxy modes. Proxy mode remains available in the tray tooltip and menu; mode-specific tray artwork has not been recreated.
