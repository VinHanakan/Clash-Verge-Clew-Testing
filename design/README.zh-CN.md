# 应用图标

[English](README.md) | 简体中文

`../Clash Verge Clew.png` 是项目负责人提供的原始图片。`app-icon-source.png` 是编辑后的图标源图，用于生成 `src-tauri/icons/` 和 `src/assets/image/` 中的打包资源。

编辑保留了白色猫头和猫爪线条以及蓝紫色圆角方形区域，只把圆角方形轮廓外不透明的近白色角落改成真正的透明区域。编辑时使用的指令要求保留原有线条，不增加文字或其他元素。之后使用 Tauri CLI 生成应用、安装器及前端所需的图标尺寸。

默认托盘图标在所有代理模式下使用同一图形。代理模式仍显示在托盘提示与菜单中；尚未重新制作按模式变化的托盘图标。
